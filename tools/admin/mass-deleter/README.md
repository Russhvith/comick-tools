# mass-deleter

Bulk deletes entries on ComicK.

Deletes are not reversible. Always do a dry run first once the flag exists.

## Setup

Do the repo wide [setup](../../../docs/setup.md) first, then:

```bash
pip install -r tools/admin/mass-deleter/requirements.txt
```

## Config

Read from the root `.env`:

| Variable | Notes |
| --- | --- |
| `COMICK_SESSION_TOKEN` | See [auth.md](../../../docs/auth.md). |
