# Getting help

Stuck, confused, or not sure something's working right? Here's where to go.

## First, check the guides

Most questions are answered in one of these:

| Question | Guide |
| --- | --- |
| How do I start it? | [Starting it](run/README.md) |
| Where do I get my cookie? | [Auth](docs/auth.md) |
| What does each setting do? | [Setup](docs/setup.md) |
| How does a tool work? | Its README: [Crunchyroll Importer](tools/public/crunchyroll-importer/README.md), [Mass Deleter](tools/admin/mass-deleter/README.md) |
| How does it all fit together? | [How it works](docs/architecture.md) |

## Then, ask

| For | Use |
| --- | --- |
| Something broken | [A bug report](https://github.com/Russhvith/comick-tools/issues/new?template=01-bug-report.yml) |
| An idea for something new | [A new feature request](https://github.com/Russhvith/comick-tools/issues/new?template=02-new-feature.yml) |
| An idea to change something | [An improvement request](https://github.com/Russhvith/comick-tools/issues/new?template=03-improvement.yml) |
| A quick question or a chat | Discord: **@russhvith** |
| Anything else | Email: **me@russhvithdesign.in** |
| A security problem | Privately, see [Security](SECURITY.md) |

Before opening an issue, have a quick look through the [existing ones](https://github.com/Russhvith/comick-tools/issues?q=is%3Aissue), someone may have asked already.

## Good to know

- **Never share your session cookie or `.env` file** with anyone, including in screenshots or logs. Nobody helping you needs it.
- **This is a spare time project.** Answers can take a day or two. Being clear about what you tried helps a lot.
- **Problems with ComicK itself** (the website, your account, review decisions) are for ComicK's own support, not this project.
